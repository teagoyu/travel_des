# 卡通旅行手账版整站设计规格

## 目标

将现有“山海之间”旅行规划网站统一升级为参考图所示的卡通旅行手账风格：轻盈、明亮、可收藏、适合分享。保留现有路线规划、高德核验、天气、住宿、Plan B、分享截图和路线 GIF 能力，只调整信息组织、视觉表现和动画素材体系。

## 视觉语言

- 色彩：天空蓝、奶油白、深海蓝为主；珊瑚橙、明黄、草绿作为状态和重点色。
- 字体：圆润中文正文，手写/展示字体用于标题、城市名和贴纸文案。
- 形态：大圆角卡片、照片相框、胶带、邮票、虚线、贴纸、爱心、星星和手绘线条。
- 背景：浅蓝天空渐变、云朵和低饱和山丘/城市剪影，避免纯色空背景。
- 统一素材：人物、汽车、相机、行李箱、飞机、景点图标和天气图标可同时复用于网页、GIF和分享海报。

## 页面改造

### 1. 首页规划页

- 顶部使用卡通旅行者和“我的旅行地图”主视觉。
- 出发地、目的地、日期、天数、路线类型等字段放入手账式输入卡。
- 城市输入保持默认收起，输入后显示带图标的城市建议卡。
- 主按钮改为“开始规划这段旅程”，旁边保留示例路书入口。
- 下方展示“去过的地方 / 热门路线 / 规划步骤”三类内容。

### 2. 路书总览页

- 顶部显示旅行标题、人物插画、总天数、总里程和旅行标签。
- 路线图改为浅色插画底图：蓝色虚线、卡通车辆、城市邮票节点。
- 每个城市节点支持显示日期、停留天数和代表性地标图标。
- 总览区域增加“路线亮点、驾驶强度、预算状态、天气提示”四个摘要贴纸。

### 3. 每日行程页

- 每天使用一张独立的“旅行记录卡”。
- 卡片结构：DAY 标识、路线标题、当日摘要、时间线、风景、美食、住宿、风险提示。
- 时间线使用卡通图标区分出发、休息、午餐、景点、入住和返程。
- 风景、美食和酒店使用相框式小卡，不再使用重复的大面板。
- 每天保留“调整这一天”和“生成 Plan B”操作。

### 4. 侧栏与收藏

- 侧栏标题改为“我的旅行清单”或“沿途收藏”。
- 每日风景使用城市卡片，显示 DAY、城市、景点贴纸和图片来源。
- 支持点击城市卡片跳转到对应日期。
- 住宿、美食、风景统一使用相同的卡片组件和状态标签。

### 5. 分享与动画

- 分享截图改为参考图一样的长图旅行档案：路线概览、城市照片卡、旅行清单和一句总结。
- GIF 改为卡通旅行手账动画：角色开场、卡通车沿虚线移动、城市贴纸弹出、每日卡片切换、总结页收尾。
- 网页、分享图和 GIF 使用同一组颜色、图标和插画素材。

## 数据与功能约束

- AI 负责路线建议、每日拆分、文案和主题标签。
- 高德负责城市、地点、路线距离和驾驶耗时核验。
- 天气、住宿价格和图片必须标注来源及更新时间。
- 数据缺失时显示“待补充 / 待核验”，不能用卡通内容伪装成真实数据。
- 现有匿名会话、Plan B、路线下载和分享链接功能保持兼容。

## 实施顺序

1. 建立颜色、字体、贴纸、图标和卡片的视觉令牌。
2. 重构首页规划页。
3. 重构路书总览和每日行程页。
4. 抽取风景、美食、住宿、路线节点的统一卡片组件。
5. 将同一套视觉素材接入分享长图和卡通 GIF。
6. 验证桌面端、窄屏、动画生成、下载和已有功能点击路径。

## 验收标准

- 首页和路书页一眼可识别为同一套卡通旅行手账产品。
- 每日行程信息比当前更丰富，但仍能快速阅读。
- 路线、天气、住宿、Plan B和分享功能继续可用。
- GIF预览、MP4/GIF下载和分享截图均能正常生成。
- 缺失数据有明确状态，不产生误导性展示。
