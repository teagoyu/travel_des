# 旅行杂志式路书页面改版

## 目标

把当前“多面板后台感”的路书详情页改成更像旅行杂志的长页：首屏讲清路线故事，路线用轻量 SVG 时间线表达，每日内容以阅读为主，右侧只保留高价值信息。

## 设计约束

- 保留现有功能：高德核验、分享截图、复制文案、每日调整、Plan B、天气、住宿、清单和只读分享。
- 暂不新增或生成图片素材；继续复用现有资源。
- SVG 路线图继续作为示意路线，不引入真实地图底图。
- 移动端仍需单列显示，按钮保持可点击和可见焦点。

## 页面结构

1. TripHero：大标题、路线摘要和核心元信息保持首屏焦点。
2. RouteOverview：缩短上下留白，作为轻量路线时间线放在首屏之后。
3. Daily：在每日区增加紧凑的日期导航；每日卡片减少边框和重复面板，突出当天路线、天气和时间轴。
4. Rail：右侧只保留每日风景导航、今晚住宿和出发前清单；推荐内容使用更轻的杂志式信息块。
5. Footer：预算、数据来源、分享区保持功能完整，但降低视觉权重。

## 验收标准

- 首屏进入每日区前，不再出现连续的大面积普通面板。
- 每日导航可点击并滚动到对应日；调整和 Plan B 按钮仍可用。
- 桌面端为主栏 + 窄侧栏，移动端自动单列。
- TypeScript 检查通过，页面可在本地路书 URL 正常加载。
